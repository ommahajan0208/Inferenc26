# Visual Documentation

This directory contains visual diagrams, charts, and reference materials for the Inferenc26 repository.

## Directory Structure

### `architecture/`
System and component architecture diagrams, data-flow visualizations, and module relationships.

**Contents:**
- `system_architecture.png` - High-level system architecture diagram
- `dataflow_diagram.png` - Data flow and processing pipeline diagram

### `workflows/`
Development workflow diagrams, operational procedures, and execution flow visualizations.

**Contents:**
- `dev_workflow.png` - Standard development workflow
- `round2_strategy_workflow.png` - Round 2 strategy execution workflow

### `round1_round2/`
Strategy-specific visualizations, analysis outputs, and competition-related materials.

**Contents:**
- `AfterRound1.png` - Round 1 competition results and performance metrics
- `AfterRound2.png` - Round 2 competition results and strategy performance
- `final_leaderboard.png` - Final competition leaderboard showing rankings and outcomes

## Image Naming Conventions

- Use lowercase with underscores: `system_architecture.png`
- Include descriptive names that indicate content
- Use PNG format for diagrams (lossless, suitable for vector content)
- Use JPEG for photographs or complex images

## How to Reference Images

### In Markdown Files
```markdown
![Description](path/to/image.png)
```

### In Documentation
Reference images alongside Mermaid diagrams to provide both code-based and visual representations.

## Updating Visual Documentation

1. When creating or updating diagrams, save them to the appropriate subdirectory
2. Update the relevant markdown files in `docs/` to reference the new images
3. Keep Mermaid diagrams and PNG versions synchronized where applicable
4. Update this README with any new subdirectories or images added
